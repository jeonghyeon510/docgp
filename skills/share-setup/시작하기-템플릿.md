## 1단계 — 압축 풀기

zip 파일을 **바탕화면이나 문서 폴더**처럼 찾기 쉬운 곳에 옮긴 뒤 압축을 푼다.

| | 방법 |
|---|---|
| **Windows** | 파일 우클릭 → `압축 풀기` → `압축 풀기` 버튼 |
| **macOS** | 파일을 더블클릭 |

> **다운로드 폴더에서 바로 풀지 말 것.** 나중에 파일을 못 찾는 가장 흔한 원인이다.

> **Windows — zip을 더블클릭해서 열린 창을 그대로 쓰면 안 된다.**
> 폴더처럼 보이지만 아직 압축이 풀린 게 아니다. 그 상태로 다음 단계를 진행하면
> 파일이 열리긴 해도 **고친 내용이 하나도 저장되지 않는다.**
> 반드시 `압축 풀기`를 눌러서 새로 생긴 폴더를 쓴다.

## 2단계 — Antigravity 설치

<https://antigravity.google> 에 접속해 내 컴퓨터에 맞는 버전을 받아 설치한다.
처음 실행하면 Google 계정 로그인을 요구한다. 평소 쓰는 계정으로 로그인하면 된다.

> macOS에서 "확인되지 않은 개발자" 경고가 뜨면
> `시스템 설정` → `개인정보 보호 및 보안` → 아래쪽 `확인 없이 열기`를 누른다.

## 3단계 — 폴더 열기

Antigravity를 실행하고 메뉴에서 **`File` → `Open Folder...`** 를 고른다.
1단계에서 압축을 푼 폴더(`{{PROJECT}}`)를 **선택만 하고** 열기를 누른다.

> **폴더를 골라야 한다.** 폴더 안으로 들어가서 파일 하나를 여는 게 아니다.
> 이걸 잘못하면 아래 스킬들이 동작하지 않는다.

처음 열면 "이 폴더의 작성자를 신뢰합니까?" 같은 질문이 나온다. **신뢰**를 고른다.

## 5단계 — 처음 한 번만 해둘 설정

권한 설정은 **파일로 전달되지 않아서** 각자 자기 컴퓨터에서 해줘야 한다.
어렵지 않다. 채팅창에 이렇게 쓰면 알아서 안내해준다.

```
안티그래비티 설정 알려줘
```

특히 아래 두 개는 처음에 꼭 확인한다.

- **Terminal Execution Policy** — 에이전트가 명령을 실행할 때 나에게 물어볼지 정한다.
  처음에는 `Request Review`(매번 확인)로 두는 것을 권한다.
- **Agent Non-Workspace File Access** — 이 폴더 **바깥** 파일은 기본적으로 못 읽는다.
  "파일이 분명히 있는데 못 찾겠다"고 하면 대개 이 설정 때문이다.

## 이제 뭘 하면 되나

채팅창(`Ctrl/Cmd + L`)에 **평소 말하듯이** 부탁하면 된다. 명령어를 외울 필요 없다.

```
이 프로젝트가 뭐 하는 건지 설명해줘
발표자료 검토해줘
```

## 잘 안 될 때

| 증상 | 이렇게 해본다 |
|---|---|
| 스킬 목록을 모른다고 답한다 | 3단계를 다시 — 폴더가 아니라 파일을 열었을 가능성이 높다 |
| macOS에서 `.agents` 폴더가 안 보인다 | 정상이다. 점(`.`)으로 시작하는 폴더는 숨겨진다. `Cmd + Shift + .` 로 보였다 숨겼다 할 수 있다 |
| 명령을 실행할 때마다 물어본다 | 정상이다. 5단계의 Terminal Execution Policy에서 바꿀 수 있다 |
| 답을 영어로 한다 | `AGENTS.md` 파일이 같이 열렸는지 확인한다 |
| 파일을 못 찾겠다고 한다 | 그 파일이 이 폴더 **안**에 있는지 확인한다 |

그래도 안 되면 이 폴더를 보내준 사람에게 **어느 단계에서 막혔는지**와 화면 캡처를 보내면 된다.
