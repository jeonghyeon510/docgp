# 에이전트 설정 공유

이 프로젝트의 에이전트 설정을 **zip 하나**로 묶어서 다른 사람에게 넘긴다.
받는 사람은 압축을 풀고 Antigravity로 폴더를 열기만 하면 된다. 설치도 명령어도 없다.

## 무엇을 넘겨야 하는가

에이전트를 움직이는 것은 프로젝트 폴더 안의 **세 가지**뿐이다.

| 항목 | 역할 |
|---|---|
| `.agents/skills/` | 스킬 — 특정 작업을 할 때 꺼내 쓰는 절차서 |
| `.agents/mcp_config.json` | MCP 서버 등록 — 받는 사람이 따로 등록하지 않아도 켜진다 |
| `GEMINI.md` (또는 `AGENTS.md`) | 에이전트가 항상 지키는 프로젝트 규칙 |

셋 다 프로젝트 폴더 안에 있어서 폴더째 넘기면 그대로 따라간다.
반대로 전역 설정(`~/.gemini/config/`)에 둔 것은 **넘어가지 않는다.**
그래서 공유할 설정은 프로젝트 쪽에 두고, 이 프로젝트가 그렇게 되어 있다.

**파일로 넘어가지 않는 것** — 받는 사람이 자기 컴퓨터에서 직접 해야 한다.

- 터미널 실행 권한 (Terminal Execution Policy, Allow/Deny List)
- 프로젝트 밖 파일 접근 허용 여부
- 확장(Open VSX), 전역 `~/.gemini/config/`에 등록한 MCP

MCP를 같이 넘길 거라면 **받는 사람 컴퓨터에 Node.js가 필요하다.** 없으면 그 서버만 안 뜨고
나머지는 정상 동작한다. 안내문이 이 점을 알려준다.

이 항목들은 zip에 같이 들어가는 `시작하기.md`가 안내하므로 따로 설명하지 않아도 된다.

## 절차

### 1. 무엇을 담을지 정한다

사용자에게 확인한다. 애매하면 **설정만**이 기본이다.

| 모드 | 담기는 것 | 언제 |
|---|---|---|
| **설정만** (기본) | `AGENTS.md` + `.agents/` | 상대가 자기 프로젝트에 이 에이전트를 얹고 싶을 때 |
| **전체** (`--full`) | 프로젝트 파일 전부 | 같은 팀원이 이 작업을 이어받을 때 |

### 2. 묶는다

```bash
python3 .agents/skills/share-setup/pack.py            # 설정만  → agent-setup.zip
python3 .agents/skills/share-setup/pack.py --full     # 전체    → <폴더명>.zip
```

| 옵션 | 효과 |
|---|---|
| `-n 이름` | zip 파일명 지정 |
| `--with-rules` | 빈 서식 대신 **이 프로젝트의 실제 규칙 파일**을 담는다 |
| `--for "이름"` | 안내문 첫머리에 이름을 넣는다 (강의명 등). 생략하면 아무 이름도 안 들어간다 |

파일명은 zip 안의 **최상위 폴더명이기도 하다.** `agent-setup.zip`을 풀면 `agent-setup/` 폴더가 나온다.

### 규칙 파일은 기본적으로 빈 서식이 들어간다

이 프로젝트의 `GEMINI.md`/`AGENTS.md`에는 이 프로젝트에만 해당하는 내용(파일명, 기획 내용)이 들어 있다.
그대로 넘기면 받는 사람에게는 맞지 않는 규칙이 되므로, **채워 넣을 수 있는 빈 서식**을 대신 담는다.

같은 프로젝트를 이어받는 사람이라 실제 규칙까지 필요하다면 `--with-rules`를 쓴다.

윈도우에서는 `python3` 대신 `python`을 쓴다. 추가 설치는 필요 없다.

`시작하기.md`(받는 사람용 안내문)는 스크립트가 **자동으로 만들어 넣는다.**
현재 스킬 목록을 읽어서 채우므로 직접 작성하지 않는다.

`.git`, `.DS_Store`, `node_modules`, `__pycache__`, `.zip`은 자동으로 빠진다.

파일명은 기본값(영문)을 그대로 쓰는 편이 안전하다. 일부 윈도우 압축 프로그램이 zip 안의
한글 폴더명을 깨뜨려서, 받는 사람 화면에 알아볼 수 없는 이름으로 풀리는 일이 있다.

### 3. 확인한다

zip을 넘기기 전에 실행 로그를 본다.

- 담긴 파일 개수가 예상과 맞는가 (설정만 = SKILL.md 개수 + `AGENTS.md` + 안내문)
- 용량이 지나치게 크지 않은가 — 100MB가 넘으면 메일·메신저로 전송이 막힌다.
  `--full`에서 크다면 내보낸 PPTX·PDF나 이미지가 원인이니 설정만 모드를 권한다
- API 키나 개인 정보가 담긴 파일이 섞여 있지 않은가 (`--full`일 때 특히)

### 4. 전달한다

zip 파일 **하나만** 보내면 된다. 메일·메신저·드라이브 무엇이든 상관없다.
받는 사람에게는 이 한 줄만 전하면 충분하다.

> 압축 풀고 안에 있는 `시작하기.md` 부터 읽으세요.

## 주의할 점

- **압축을 다시 풀어보고 보낸다.** 특히 `--full`로 만든 뒤에는 한 번 확인하는 편이 낫다
- **빈 폴더는 zip에 담기지 않는다.** 비어 있는 폴더는 사라지므로,
  받는 쪽에서 필요하다면 안에 파일이 하나라도 있어야 한다
- **개인 API 키를 담지 않는다.** 키는 코드가 아니라 환경변수로 각자 넣게 한다.
  `--full`로 묶기 전에 키가 적힌 파일이 없는지 확인한다
- 상대가 Antigravity를 처음 쓴다면 설정 항목까지 묻는 경우가 많다.
  그때는 `antigravity-setup` 스킬로 안내한다
